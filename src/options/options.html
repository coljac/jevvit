Jevvit

Filter Reddit with Jev. Each story in a listing is judged against your prompt, and the ones you don't want are collapsed, hidden or dimmed.

1. Connect to Jev

Kept in this browser only and never synced. It goes nowhere but the API address below, and Reddit's pages never see it. Make a key just for Jevvit at console.typesafe.ai so you can revoke it on its own.

Advanced

jev-latest moves to newer releases as they appear. Pin a versioned name such as jev-1.13.0 if you want the same judgement every time.

Only change this for a proxy or a local test server. It must be https (or http on localhost).

2. What should it filter?

Plain English, as a question or a statement. Make it a yes/no that can be answered from the title, the subreddit and the link: Is this about …? works well. Jev only ever answers with a probability, so a post can't make it do anything else, but posts are written by strangers who may try to sway it: expect the odd miss.

What to do with a match
Sharpen the boundary (optional)

Often the prompt alone is enough. If Jev is getting the grey areas wrong, say what counts on each side, including the case you'd have to think about yourself.

3. How strict?

Jev answers with a probability, so a story it is only 55% sure about is better nudged than removed. Raise the first slider to filter less; set the second to 0 to switch dimming off.

Filtered stories are

Hiding completely can make Reddit load page after page to fill the screen if your prompt is strict; collapsing avoids that.

Sent to Jev for each story: the subreddit, title, flair, link domain, post type and (if enabled) that body excerpt. Never your username, votes or anything from your account. Jev bills input only, about $0.04 per million tokens: with a short prompt, roughly a cent per thousand stories. Remembered verdicts cost nothing.

4. Try it

Judge one made-up or pasted story with the settings above, before saving. This sends one request.
